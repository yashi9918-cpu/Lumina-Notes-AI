# 📚 Lumina Notes AI

An AI-powered study assistant that helps students learn smarter from their own notes.

---

## 🚀 Features

- 📄 Upload PDF Notes
- 🤖 AI Summary Generator
- 💬 AI Chat with Notes
- 📝 AI Quiz Generator
- 🧠 AI Flashcards
- 📥 Download Summary as PDF

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- Multer
- PDF-Parse

### AI
- Google Gemini API

---

## 📂 Project Structure

```
StudyGenie/
├── frontend/
├── backend/
└── uploads/
```

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yashi9918-cpu/Lumina-Notes-AI.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `backend` folder:

```
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```
